# BudgetApp

BudgetApp is an Android personal finance application built with Kotlin and Jetpack Compose.

The app allows users to track expenses, set monthly budgets, manage spending categories and monitor progress through an XP and streak-based gamification system.

## Features

- Add expenses with amount, category and optional notes
- View expense history
- Set and update monthly budgets
- Track monthly spending against budget
- Create and delete custom spending categories
- Store app data locally using Room
- XP and streak system to encourage consistent expense tracking

## Tech Stack

- Kotlin
- Android SDK
- Jetpack Compose
- Material 3
- Room Database
- ViewModel
- StateFlow
- Kotlin Coroutines
- Repository Pattern
- DAO / SQL queries
