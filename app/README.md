# Budget App
This is a simple Android app I made for tracking personal spending.
My goal was to create something simple to use so people can see where their money is going.
The app lets the user add expenses, view history and organise spending through categories.
The user can add and delete categories. I also added gamification through an XP and streak system.

# Main Features
- Add an expense with amount,category,date and an optional note
- View all past expenses in a separate history screen
- Dashboard that shows total amount spent in the month and a bar with how much of the budget is left
- Manage categories: here the user can add and delete categories depending on what they spend money on
- Clear all expenses: I have added a button to clear all expenses previously added
- Simple gamification: I've added a simple gamification, a streak and XP system, similar to what many apps have. 

# Gamification
I decided to use an XP and streak system as its simple and widely used in apps today. 
This rewards the user's consistency and makes the app feel more motivating

# Technology Used
- Kotlin
- Room Database
- ViewModel + StateFlow
- Material 3

The app is focused on helping users keep track of their spending in a simple and engaging way
The target audience would be possibly students,who are on strict budgets, or anyone with saving goals to meet.
